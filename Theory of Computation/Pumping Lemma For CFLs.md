##  Motivation & Intuition
Just like the [[Pumping Lemma For Regular Languages]] checks for "loops" in a [[Finite Automata]], the **Pumping Lemma for CFLs** checks for **repeating variables** in a long path of a [[Parse Tree]].

**The Intuition:** If a string is long enough, some variable $A$ MUST repeat on a path in the tree. This repeating $A$ allows us to "pump" (repeat or remove) the portion of the string derived between the two occurrences of $A$.

##  Theory
### Statement
If $L$ is a Context-Free Language, there exists a **pumping length** $p$ such that any string $s \in L$ with $|s| \ge p$ can be split into five parts $s = uvwxy$ satisfying:
1. $uv^iwx^iy \in L$ for all $i \ge 0$.
2. $|vx| > 0$ (at least one of $v$ or $x$ is non-empty).
3. $|vwx| \le p$.

### Why does it work? (The CNF Connection)
In a [[Chomsky Normal Form]] grammar, if a parse tree has height $h$, the maximum length of the string is $2^{h-1}$.
If $|s| > 2^{|V|-1}$, where $|V|$ is the number of variables, the tree must have a height $> |V|$.
By the **Pigeonhole Principle**, some variable $A$ must repeat on the longest path.

##  Visuals
### The $uvwxy$ Decomposition
```text
        [S]
       /   \
      u   [A] <--- Occurrence 1
         /   \
        v   [A] <--- Occurrence 2
           /   \
          w     x
               / \
              y
```
- $w$ is what the lower $A$ generates.
- $vwx$ is what the upper $A$ generates.
- $v$ and $x$ are the "pumpable" flanking strings.

##  Complexity Analysis
**Proving $L$ is NOT CFL:**
1. Assume $L$ is CFL. Let $p$ be the pumping length.
2. Choose a string $s \in L$ such that $|s| \ge p$.
3. Analyze all possible ways to split $s = uvwxy$.
4. Show that for some $i$, $uv^iwx^iy \notin L$.

##  Worked Example
**Language:** $L = \{ a^n b^n c^n \mid n \ge 1 \}$

1. **Assume** $L$ is CFL. Let $p$ be the pumping length.
2. **Choose** $s = a^p b^p c^p$. Note $|s| = 3p \ge p$.
3. **Split** $s = uvwxy$ such that $|vwx| \le p$.
4. **Cases for $vwx$:**
   - Case 1: $vwx$ contains only $a$'s (or only $b$'s or only $c$'s).
     If we pump ($i=2$), the counts of $a, b, c$ will be unequal.
   - Case 2: $vwx$ contains $a$'s and $b$'s (but no $c$'s).
     If we pump ($i=2$), the count of $c$ remains $p$, but $a$ or $b$ (or both) will increase. Count($a$) or Count($b$) $\ne$ Count($c$).
   - Case 3: $vwx$ cannot contain all three ($a, b, c$) because $|vwx| \le p$, and there are $p$ $b$'s between $a$'s and $c$'s.
5. **Conclusion:** In all cases, $uv^2wx^2y \notin L$. So $L$ is NOT CFL.

##  GATE Questions
**Question (GATE-style):**
Which of the following languages is context-free?
(A) $L = \{ a^n b^n c^n \mid n \ge 1 \}$
(B) $L = \{ a^n b^m a^n b^m \mid n, m \ge 1 \}$
(C) $L = \{ a^n b^n \mid n \ge 1 \}$
(D) $L = \{ a^i b^j c^k \mid i=j=k \}$
<details>
<summary>Solution</summary>
**Answer: (C)**
(A), (B), and (D) are classic non-CFLs that fail the Pumping Lemma. (C) is a standard CFL (can be generated by $S \to aSb | ab$).
</details>

##  Edge Cases & Traps
- **Constraint $|vwx| \le p$:** Students often forget this. It limits how many "types" of symbols $v$ and $x$ can contain.
- **Pumping Down ($i=0$):** Sometimes pumping down ($uv^0wx^0y = uwy$) is the easiest way to find a contradiction.
- **Pumping vs Regular PL:** Regular PL uses $xyz$ ($y$ pumps), CFL PL uses $uvwxy$ ($v, x$ pump).
